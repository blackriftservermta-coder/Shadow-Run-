SHADOW RUN: ROOFTOP CHASE — نمونه اولیه چندنفره

فایل‌ها:
- public/index.html: بازی سه‌بعدی
- server.js: سرور هماهنگ‌کننده بازیکنان
- package.json: تنظیمات سرور

تمرین آفلاین:
فایل public/index.html را در مرورگر باز کن؛ برای بارگذاری Three.js به اینترنت نیاز دارد.

بازی آنلاین:
این پروژه به میزبان Node.js با پشتیبانی WebSocket نیاز دارد.
1) فایل ZIP را روی میزبان سازگار با Node.js قرار بده.
2) دستور npm install را اجرا کن.
3) دستور npm start را اجرا کن.
4) آدرس HTTPS میزبان را در کادر «آدرس سرور HTTPS» بازی وارد کن.
میزبانی فقط HTML کافی نیست؛ سرور server.js نیز باید اجرا شود.

محدودیت‌ها:
این نسخه نمونه اولیه است، نه نسخه نهایی انتشار. حساب کاربری، اتاق‌ها، ضدتقلب و ذخیره ابری هنوز ندارد. سرویس‌های رایگان یا سایت‌های میزبانی ممکن است از داخل ایران در دسترس نباشند؛ دسترسی و شرایط را پیش از انتخاب بررسی کن.
